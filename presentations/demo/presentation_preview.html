Нужен ли вам CLI?

Без CLI (Рекомендуется по умолчанию)
• Интерактивный просмотр прямо в браузере
• Управление клавишами: Space, стрелки, F (полный экран)
• Полная автономность файла (работает без интернета)
• Сохранение в PDF через стандартный диалог печати
С CLI (Подключаем по запросу)
• Требуется только если нужен настоящий файл .PPTX для MS Office
• Пакетная сборка презентаций в фоне через Marp CLI
• Автоматический рендеринг без открытия окна браузера
